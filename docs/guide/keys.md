# Everyday keys

<kbd>Super</kbd> is the Windows key. These are the bindings you will use all day; the complete,
searchable list is on <kbd>Super</kbd>+<kbd>K</kbd>.

## Open things

| Action | Keys |
|---|---|
| Menu | <kbd>Super</kbd>+<kbd>Space</kbd> |
| App launcher | <kbd>Super</kbd>+<kbd>Alt</kbd>+<kbd>Space</kbd> |
| Terminal | <kbd>Super</kbd>+<kbd>Enter</kbd> |
| Terminal with tmux | <kbd>Super</kbd>+<kbd>Alt</kbd>+<kbd>Enter</kbd> |
| Drop-down terminal | <kbd>Super</kbd>+<kbd>`</kbd> |
| Browser (Brave) | <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> |
| File manager (Thunar) | <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> |
| Containers (podman-tui) | <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> |

## Windows and workspaces

| Action | Keys |
|---|---|
| Close window | <kbd>Super</kbd>+<kbd>W</kbd> |
| Fullscreen | <kbd>Super</kbd>+<kbd>F</kbd> |
| Float or tile | <kbd>Super</kbd>+<kbd>T</kbd> |
| Move focus | <kbd>Super</kbd>+<kbd>arrows</kbd> |
| Swap windows | <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>arrows</kbd> |
| Switch workspace | <kbd>Super</kbd>+<kbd>1</kbd> to <kbd>0</kbd> |

## Clipboard

These work the same in every app, including the terminal.

| Action | Keys |
|---|---|
| Copy / paste / cut / select all | <kbd>Super</kbd>+<kbd>C</kbd> / <kbd>V</kbd> / <kbd>X</kbd> / <kbd>A</kbd> |
| Clipboard history | <kbd>Super</kbd>+<kbd>Ctrl</kbd>+<kbd>V</kbd> |

Selecting text with the mouse in the terminal copies it too.

## Panels

| Action | Keys |
|---|---|
| Control center | <kbd>Super</kbd>+<kbd>S</kbd> |
| Session menu (logout, reboot, shutdown) | <kbd>Super</kbd>+<kbd>Esc</kbd> |
| Lock | <kbd>Super</kbd>+<kbd>Ctrl</kbd>+<kbd>L</kbd> |
| Wallpaper panel | <kbd>Super</kbd>+<kbd>Ctrl</kbd>+<kbd>Space</kbd> |
| Theme carousel | <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>Ctrl</kbd>+<kbd>Space</kbd> |
| Wallhaven browser | <kbd>Super</kbd>+<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Space</kbd> |
| Noctalia settings | <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>,</kbd> |
| All key bindings | <kbd>Super</kbd>+<kbd>K</kbd> |

## Screenshots and recording

| Action | Keys |
|---|---|
| Screenshot of an area | <kbd>Print</kbd> |
| Screenshot of a window | <kbd>Shift</kbd>+<kbd>Print</kbd> |
| Screenshot of the screen | <kbd>Ctrl</kbd>+<kbd>Print</kbd> |
| Record an area (press again to stop) | <kbd>Alt</kbd>+<kbd>Print</kbd> |
| Record the screen (press again to stop) | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Print</kbd> |

## tmux

| Action | Keys |
|---|---|
| Prefix | <kbd>Ctrl</kbd>+<kbd>Space</kbd> |
| Split | <kbd>Alt</kbd>+<kbd>Enter</kbd> |
| Switch window | <kbd>Alt</kbd>+<kbd>1</kbd> to <kbd>9</kbd> |

The full tmux list is in the menu under Learn > Tmux keybindings.
